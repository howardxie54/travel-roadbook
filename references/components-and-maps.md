# 固定组件与可移植地图

先用包内组件，再设计目的地主题。提示词负责研究与审美取舍，代码负责稳定交互，实际渲染负责验收。不能只写“漂亮、精致、有氛围”就让用户收尾。

## 主题与组件边界

可变：目的地意象、七个主题色、标题构图、装饰、图片与文字。固定：完整功能、控件尺寸、信息层级、状态反馈、预览位置和可访问语义。主题使用 visualTheme.palette；components.css 最后加载，不允许主题覆盖组件结构。正文、每日卡片、提醒、美食、订单和导航都要检查，不能遗留原版绿色。

完整配色契约见 theme-isolation.md。项目装饰通过 visualTheme.stylesheet 加载在固定组件之前，control-theme.css 在组件尾部统一普通与交互状态；不得将项目 CSS 再追加到最终 HTML 的尾部。基础模板内部仅引用语义变量，酒店按钮不再绘制第二层旧色伪元素。

默认按钮至少 44px 高、圆角 12px、图标 18px、文字与图标间距 8px。主要动作 accent 实底，次要动作 accent-soft 与细边框；有聚焦、按下和禁用反馈。外链也使用完整按钮容器与 SVG 图标，不堆裸箭头。全文强调色一致。

## 天数布局

| 天数 | 桌面概览 | 手机概览 | 预览位置 |
|---|---|---|---|
| 1–4 | 等宽卡片，列数等于天数 | 两列，奇数末项跨整行；320px 单列 | 整组卡片紧邻下方 |
| 5–14 | 日期 / 城市 / 图标的全宽列表 | 相同列表，城市名完整换行 | 被点的那一天正下方 |
| 15 天以上 | 同样列表，可由城市/周分组增强 | 保持相同信息顺序 | 被点的那一天正下方 |

长列表最大 520px，受控滚动，不因天数不同形成参差四列。每行显示完整“第 N 天”和城市名，不能只剩“曼…”；过长则增加行高。展开区域 44×44px，只有一个上下 chevron，展开后转向，同步 aria-expanded 与可访问名称。再次点同一天收起，不在预览内部放第二个收起按钮。显示整天详情是独立实底按钮，先预览再进入，不突然跳往页面末尾。

逐日导航始终单行横向滚动，当前日期和键盘选中项自动可见。日期未知用“第 N 天”，不能删除日期标签。测试 3/6/8/9/10/11 等奇偶情况，并用长城市名检验。

## 包内地图生成器

scripts/geographic_map.py + map_layout.py 使用核实经纬度与统一 Web Mercator 投影。assets/world-land.geojson 是 Natural Earth 110m 世界轮廓；无需额外地图、动画或设计 Skill，无 API Key 时仍能生成离线轮廓地图。在线街道瓦片为可选增强，失败时城市、连线、轮廓与播放保留。粗轮廓不等于精确导航，不把旅行连线称为实际铁路、公路或飞行航迹。

按住宿晚数、活动天数和用户意图判断主要游玩地区，不让长距离出发点撑大主图。城市保存 label/lon/lat/country/role；出发地 role=origin，离开后地点 role=exit。用 geographicMap.focusCountry 和 focusIndices 明确目的地索引，focusLabel 描述区域，onlineTiles=false 可关闭外部街道瓦片。landAsset/roadsAsset 可指定项目内更详细且允许使用的数据。

主图展示游玩城市，小图展示抵达/离开和出发点，两图各自投影。routeSegments 保存真实顺序与 from/to/mode/source；播放自动根据区段端点在主图与小图之间切换，支持多段和往返。小图避开主要地点；超过六个游玩城市用数字点和完整城市图例，防止文字堆叠。经度按最短跨度处理跨日期变更线。

只有国家名而无城市时，不编造东京等站点。缺检索能力且无用户坐标时，先保留明确标为非地理底图的路线顺序图，坐标补充后升级。只有一个核实地点时生成静态地区图并隐藏播放，不造第二座城市。

## 交通插画继承

真实 routeSegments.mode 不变。显示依次选：本段已知交通 → 最近的前一段已知交通 → 全程第一段已知交通。因此连续待定区段都能继承。全程没有已知方式则使用中性点，不猜飞机。

继承只影响插画，仍提示“交通待确认（插画沿用飞机）”，不能写成已确定飞机。本段补充方式后自动替换，无需用户选择装饰。按路径切线镜像，角色直立。包内 transport-fallback.svg 提供飞机/汽车/火车/自行车基础图形，有宿主生图能力时再生成小猫或自定义角色，不要求生图才能播放。

## 实际验收

检查 320/390/1280px，短、长、奇数、长城市名、起始待定、连续待定、全部待定、往返与换乘。从每日正文返回点击第六天，确认预览在视口内且紧邻第六天；整天入口与收起都可用。地图目的地区域明显大于出入境小图，每段连接完整，城市相对方位正确。测试无网络、无生图素材版本以及实际下载文件。记录检查范围，组件通过不等于任意宿主与目的地都通过。
