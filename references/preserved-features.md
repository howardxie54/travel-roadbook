# 保留原版路书

这是从内蒙古实用路书抽出的功能模板。保留能力与交互，但主题、标题与按天导航必须根据目的地和天数重新设计，参见 adaptive-design.md。

| 模块 | 基础要求 | 未提供数据时 |
|---|---|---|
| 标题与日期印章 | 保留标题区域、主题意象与日期层次 | 用可替换文字/通用图形；不复用作者姓名或肖像 |
| 当天重点与倒计时 | 选择日期同步重点；带时区的关键事件倒计时 | 显示日期待补充，不能删除模块或造日期 |
| 地图与路线 | 按核实坐标和区段生成地理路线，保留播放与说明 | 坐标未知先待核实，不凭感觉摆城市；可用授权地理轮廓作为底图 |
| 角色与交通 | 默认内置交通矢量；可用用户角色，按区段自动换图 | 待定插画沿用最近已知方式或首个已知方式；全程待定用中性点，事实不改 |
| 路线概览与抽屉 | 短行程可用卡片，长行程用列表/时间轴；预览、收起、打开整天 | 每天保留可补充预览，不硬套四天卡片 |
| 每日行程 | 时间线、重点标记、地点展开、地图入口、左右滑动、键盘切换 | 用待补充站点；不造导航入口 |
| 美食推荐 | 图片/示意、理由、店铺/榜单链接与搜索、用餐节奏、展开动效 | 保留推荐区域与待补充说明 |
| 订单与住宿 | 航班/车次、集合、住宿晚数与地址、导航、门票 | 显示待补充；合成酒店不导航 |
| 提醒与待办 | 当天提醒和全程待办同步冲突与未确认信息 | 基于已有信息，不能套用沙漠安全提醒到所有旅行 |
| 手机与离线 | 底栏、安全区、触控状态、减少动效、单文件保存 | 保持原交互，实际验证 |

角色选项：中性火柴人（无需外部能力）；用户提供可使用的图片；按描述生成（仅当可用图像工具存在）。图片内嵌后可离线。不得默认使用作者个人 Q 版像。交通方式按每一区段保存，允许同一旅程飞机+火车+汽车混用。

路线播放使用 SVG 路径与浏览器动画，无需 Remotion。包内 geographic_map.py / map_layout.py 与世界地理轮廓负责核实坐标的地图；缺坐标时先交付明确标为示意的路线顺序图。需要视频时再选用可用的视频工具。

目前生成器可内嵌 titleArt 与 avatarAsset（项目内相对路径）。theme.large 支持字号增大；其他完整主题重设计由助手在保留功能前提下修改模板。推荐图片由 foodImages 提供，推荐记录沿用原版字段；没有核实资料则保持待补充。
